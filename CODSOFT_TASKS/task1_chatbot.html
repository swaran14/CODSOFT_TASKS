CodBot

A rule-based chatbot using pattern matching + a curated knowledge base. No LLM, no API calls — every reply below traces back to a regex rule you can read in the source.
  codbot — rule_engine.js
How it works: user input is lower-cased and tested against an ordered list of regex patterns (greetings, name memory, jokes, time/date, small talk). If nothing matches, it falls back to a random "I don't understand" response and a lightweight knowledge-lookup table for common facts. This mirrors chatbot.py in the repo — same logic, ported to JavaScript for the browser.

Note on "current affairs": facts like who's currently a president or CEO are hard-coded as of when this was built (mid-2026) — a rule-based bot has no internet connection, so it can't fetch live news. If asked far in the future, some of these answers may be outdated.
