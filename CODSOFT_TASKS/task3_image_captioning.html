What this actually does

This page looks at your photo and names what it recognizes (like "dog" or "beach"), then builds a simple sentence out of that. It's not writing freely like a human — it's matching your image against ~1,000 known object categories.

A "real" image captioning AI (the kind CodSoft's task describes) writes free-form sentences using a CNN + LSTM model trained on thousands of human-written captions. That version is fully built in image_captioning.py in your repo — training it just takes a dataset download and some time, which isn't practical to run inside a webpage. Use that Python version when you explain your project in the demo video.

To run the real version

pip install tensorflow tqdm pillow, download Flickr8k, then follow the steps in that folder's README.
